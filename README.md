# QuickTranslate 翻译助手

一个**后台常驻的托盘翻译工具**：在任何程序中选中文本或图片，按下热键即可通过 **OpenAI 兼容接口**翻译为指定语言，结果以浮窗形式显示在选中内容附近。WPF + C# 主程序，**C++ 原生库 (NativeCore.dll)** 负责系统级操作，两者通过 P/Invoke 互操作。

---

## 功能

- **无主窗口，启动即托盘**：右键托盘图标可进行所有操作。
- **右键菜单**：翻译为中文 / 英文 / 日语、截图翻译、生成回复、首选项、帮助、重启、退出。
- **全局热键**（默认，可在首选项中修改）：
  | 热键 | 功能 |
  |---|---|
  | `Ctrl+Alt+T` | 翻译为中文 |
  | `Ctrl+Alt+E` | 翻译为英文 |
  | `Ctrl+Alt+J` | 翻译为日语 |
  | `Ctrl+Alt+R` | 生成回复 |
  | `Ctrl+Alt+Q` | 截图翻译（**全屏框选区域**后识别） |
- **一键翻译选中内容**：在任意程序中选中文本，按热键即弹出翻译结果浮窗；选中/复制图片时自动识别图片文字。
- **截图翻译（框选）**：按热键后屏幕出现半透明遮罩，**拖拽鼠标框选**要识别的区域（`Esc` / 右键取消），松手即翻译；截图在遮罩关闭、浮窗创建**之前**完成，不会把自身界面截进去。识别方式遵循「API 设置 → 图片翻译方式」：`视觉模型` = 截图直接发给多模态模型（快、保排版、不做本地 OCR）；`本地 OCR 后翻译` = 先本地识别文字，识别不出时再退回发原图。
- **流式输出**：结果逐字实时显示在浮窗中（长文本自动换行，不撑宽窗口）。**翻译默认关闭思考**：请求里带 `thinking.type=disabled`，模型直接产出译文、首字约半秒即可见；接口不认识该参数（HTTP 400）时程序会自动去掉它重试，兼容 OpenAI 等其它兼容接口。「生成回复」保留思考过程——若模型返回思考内容（如 DeepSeek 的 `reasoning_content`），会单独在「思考过程」区域同步滚动。`Esc` 可随时取消正在生成的请求。
- **浮窗定位**：默认显示在选中内容**上方**，空间不足自动偏移到下方或覆盖，并夹紧在屏幕工作区内；`Esc` 关闭，可拖动。
- **浮窗右键菜单**：复制结果、复制原文、翻译为其他语言、重新翻译、生成回复、截图翻译、关闭。
- **图片翻译**：默认把原图发给视觉模型；模型不支持图片时**自动回退本地 OCR**（Windows.Media.Ocr）。可在首选项中切换。
- **首选项**：热键自定义（可增删多条，**每条热键可单独设置提示词**）、API 地址 / Key / 模型选择（**可一键获取模型列表**）/ 温度 / 最大输出 Token / 超时、**分功能提示词（翻译 / 生成回复 / 截图翻译）**、开机自启等。
- **生成回复的语言**：由每条热键自己的「目标语言」决定（该热键没设语言时跟随原文语言）；浮窗里的「生成回复」按钮沿用触发它的那条热键的语言，因此不再需要单独的全局设置。
- **提示词**：优先级为「**热键单独设置的提示词 > 功能默认提示词 > 内置默认**」。典型用法：把一条热键的动作设为「生成回复」，再给它单独写一套邮件回复提示词，就得到一条「专门回邮件」的热键；同时再保留一条通用回复热键互不影响。
- **打开首选项时暂停全局热键**：避免录入热键时触发已有热键（冲突），关闭窗口后自动恢复（恢复失败会在托盘气泡提示）。
- **淡蓝主题界面**：统一的淡蓝配色 + 圆角控件（按钮、输入框、下拉框、复选框、单选框、标签页、滑块、滚动条、进度条），主题集中在 `src/QuickTranslate/Themes/LightBlue.xaml`，改这一个文件即可换肤。

## 项目结构

```
QuickTranslate/
├── QuickTranslate.slnx          # VS 解决方案（含 C++ 与 C# 两个项目）
├── build.ps1 / build.cmd        # 一键构建
├── README.md
├── assets/app.ico               # 应用/托盘图标
├── scripts/make-icon.ps1        # 图标生成脚本
└── src/
    ├── NativeCore/              # ★ C++ 原生库（C API，供 C# P/Invoke 调用）
    │   ├── NativeCore.h         #   接口声明
    │   ├── NativeCore.cpp       #   Win32：模拟 Ctrl+C、剪贴板、屏幕截图、窗口/光标信息
    │   ├── OcrCppWinrt.cpp      #   C++/WinRT：Windows.Media.Ocr 文字识别
    │   ├── NativeCore.vcxproj   #   MSBuild 工程（VS 2026 / v145）
    │   └── CMakeLists.txt       #   备用 CMake 构建
    └── QuickTranslate/          # ★ WPF + C# 主程序
        ├── App.xaml(.cs)        #   入口：托盘 + 热键 + 编排
        ├── Themes/              #   淡蓝主题（配色 + 圆角控件样式）
        ├── Native/              #   user32 P/Invoke + NativeCore.dll 封装（含托管回退）
        ├── Models/              #   设置、热键、捕获结果
        ├── Services/            #   设置持久化、热键管理、托盘、选中捕获、OCR、API 客户端、编排
        └── Views/               #   首选项窗口、翻译结果浮窗、截图框选遮罩、提示词编辑器、帮助窗口
```

**C++ / C# 混编方式**：`NativeCore.dll` 以 C ABI 导出函数，C# 通过 `[DllImport]` 调用（见 `src/QuickTranslate/Native/NativeCore.cs`）。原生库缺失或调用失败时**自动回退**到托管实现，应用仍可正常工作。想扩展 C++ 能力，只需在 `NativeCore.cpp` 添加导出函数并在 `NativeCore.cs` 添加对应声明。

## 环境要求

- **构建**：Windows 10/11 + Visual Studio（含 **C++ 桌面开发** 与 **.NET 桌面开发** 工作负载）+ .NET 9 SDK。
- **运行**：Windows 10 1809+；默认发布为**框架依赖**版本（需 [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0)），也可用 `-SelfContained` 发布为免安装版本。

## 构建

```powershell
# 一键构建并发布（框架依赖）到 dist\QuickTranslate
.\build.ps1

# 或自包含免安装版本
.\build.ps1 -SelfContained

# 或仅编译不发布
.\build.ps1 -NoPublish
```

也可直接用 VS 打开 `QuickTranslate.slnx` 编译（注意：C# 项目通过 csproj 自动复制原生 DLL，若提示缺少 NativeCore.dll，先单独编译 NativeCore 项目或运行 build.ps1）。

## 使用步骤

1. 运行 `QuickTranslate.exe`，右下角托盘出现图标。
2. 右键托盘图标 → **首选项**，填入 API Key、模型（默认 `gpt-4o-mini`），可点「测试连接」验证。
   - 支持任意 OpenAI 兼容接口：OpenAI、DeepSeek、通义千问、智谱、Ollama 等，修改「接口地址」即可。
   - 不知道模型名？填好「接口地址」与「API Key」后点 **「获取模型列表」**，程序会调用 `GET {接口地址}/models` 拉取可用模型并**清空旧列表后重新填入**下拉框（同时兼容 Ollama 的 `{models:[{name}]}` 返回格式），选中后保存即可；也可以手动输入模型名。拉取到的列表会缓存到设置里，下次打开可直接选择。
   - 「测试连接」会先 `GET /models` 校验地址与 Key，再用一次最小对话请求验证模型真的能应答，失败原因（HTTP 状态与接口返回的错误信息）直接显示在按钮下方。
3. 在任意程序里**选中文本**（或选中/复制图片），按下热键（如 `Ctrl+Alt+T`）。
4. 翻译浮窗出现在选中内容附近（流式逐字显示、长文本自动换行），`Esc` 关闭，右键浮窗可复制 / 重新翻译 / 生成回复 / 切换语言。
5. 想让某条热键用专门的提示词（例如邮件回复）：首选项 → **热键** → 该行「提示词」按钮填写；三种功能的公共默认写在 **提示词** 标签页。
6. 想让某条热键用专门的回复语言：直接改那条热键的「目标语言」（如把「生成回复」热键的目标语言设为 `中文`，它就是一条中文回邮件的热键）。
7. 截图翻译：按热键后拖拽框选区域即可；发图还是先 OCR 由「API 设置 → 图片翻译方式」决定。

## 常见问题

- **热键被占用**：首选项中修改为该组合；注册失败时托盘会气泡提示。
- **图片翻译失败**：默认走视觉模型；若模型不支持图片会自动回退本地 OCR。可切换「本地 OCR 后翻译」；此时若 OCR 失败/被中断，也会自动改发原图给视觉模型，尽量保证翻译继续。
- **本地 OCR 无结果**：需系统安装相应语言包（Windows 设置 → 时间和语言 → 语言 → 添加语言）；无结果时自动回退视觉模型。
- **OCR 过程中被打断会不会中断翻译**：不会。OCR 的任何异常都会被吞掉并记录日志，随后自动改发原图给视觉模型继续翻译。
- **翻译时总是先思考很久 / 看着不像流式**：翻译请求默认带 `thinking.type=disabled` 真正关闭思考（首选项 → 通用 可关），模型会直接吐译文，首字通常半秒内出现、逐字增长。若关掉了该开关或接口不支持禁用思考，就只能隐藏思考内容，看起来会「先卡一会儿再一次性出结果」——那种情况下建议换非思考模型（如 `deepseek-chat`）。
- **按热键没翻译选中的内容 / 时好时坏**：已修。三个原因都处理了：① 剪贴板旧内容被误当成选中内容（现在必须 `Ctrl+C` 真的复制到新内容才算数）；② 旧弹窗还占着焦点时捕获（现在会先等焦点回到你原来的程序再捕获）；③ 上一次请求还在跑时静默忽略热键（现在会**打断上一次并立即执行新的**，日志里有 `打断上一次操作`）。
- **连续快速按热键没反应**：现在不会再被忽略，第二次会打断第一次并重新翻译；不想被打断就等结果出来再按。
- **「获取模型列表」失败**：先确认「接口地址」指向 OpenAI 兼容地址（OpenAI 官方为 `https://api.openai.com/v1`，DeepSeek 为 `https://api.deepseek.com`），程序会请求 `{接口地址}/models`；若服务端不提供该接口（部分自建网关），直接在「模型」框手动输入模型名即可。
- **「测试连接」报“没有内容/没有找到内容”**：多是模型把 token 全用在思考上导致正文为空（思考型模型常见）。现在测试会用足够的最小请求、同样优先关闭思考，并识别思考内容后按实际情况提示；正式翻译请把「最大输出 Token」留足余量。
- **浮窗只显示了一段思考、没有译文**：说明模型这次只输出了思考过程。程序会把思考内容显示出来并提示「可加大最大输出 Token」，而不是报错；也可在首选项 → 通用 关掉「翻译时关闭思考」查看完整过程。
- **截图翻译是发图还是先 OCR**：由「API 设置 → 图片翻译方式」决定，`视觉模型` 就直接把截图发给模型（日志写 `视觉模型直发（未做本地 OCR）`），`本地 OCR 后翻译` 才先识别文字（日志写 `OCR 结果: 长度=…`）。
- **截图翻译截到的位置不对**：`Ctrl+Alt+Q` 是全屏框选，拖拽到哪里就截哪里；`Esc` 或右键取消，误点一下也会取消。
- **生成回复用什么语言**：用该热键自己的「目标语言」；托盘菜单的「生成回复」和没设语言的热键则跟随原文语言。
- **配置存放位置**：`%APPDATA%\QuickTranslate\settings.json`；日志在 `%APPDATA%\QuickTranslate\logs\`（含捕获方式、截图选区尺寸、OCR 长度、首字耗时、思考长度等，便于排查）。

> **排查小工具**：
> - `QuickTranslate.exe --diag`：选中一段内容后运行，会自动连续捕获两次，并把前台窗口信息与捕获结果写入日志，用于确认捕获链路是否正常。
> - `QuickTranslate.exe --window=prefs|help|popup`：只打开指定窗口（首选项 / 帮助 / 示例翻译浮窗），不注册托盘与热键，用于界面调试与截图，关闭窗口即退出。

## 技术说明

- **DPI**：系统 DPI 感知（manifest），坐标换算统一处理物理像素与 WPF DIP。
- **选中内容捕获**：优先 UI Automation 的 **TextPattern 真实选中**（不干扰剪贴板）；再退到「模拟 Ctrl+C → 剪贴板序号必须变化才认 → 恢复剪贴板」；最后才在单行输入框（Edit/ComboBox，长度受限）取整个内容兜底。捕获**之前**会等前台窗口不再是本程序，避免读到自己弹窗。
- **截图翻译**：`Views/ScreenCaptureWindow.xaml` 提供全屏半透明遮罩 + 拖拽框选（`CombinedGeometry` 挖洞显示选区），选区按 DIP↔物理像素换算后由 `NativeCore.QtCaptureScreenToBmp` 截取；截图在遮罩关闭、浮窗创建**之前**完成，避免把自身界面截进图里。
- **关闭思考**：翻译类请求带上 `"thinking":{"type":"disabled"}`（实测 DeepSeek 系模型思考为 0、直出译文）；接口返回 400 时自动去掉该参数重试一次，兼容不支持此参数的兼容接口。
- **提示词解析**：`TranslateController.ResolvePrompt(热键提示词, 功能默认提示词)` 决定本次请求的 system 提示词；思考内容始终从接口读取，由调用方决定展示或暂存（翻译默认暂存，正文为空时回退展示）。
- **OCR**：优先 C++/WinRT 原生实现，回退到 C# 托管 WinRT。
- **API**：`POST {BaseUrl}/chat/completions`，支持文本与多模态（图片 base64）消息；默认 `stream=true` 流式返回，解析 SSE 增量（含 `reasoning_content` 思考内容）。模型列表通过 `GET {BaseUrl}/models` 获取。
- **界面主题**：所有控件样式集中在 `Themes/LightBlue.xaml`（`App.xaml` 中以 `MergedDictionaries` 引入），采用 WPF 控件模板重写实现圆角与淡蓝配色，不依赖第三方 UI 库。
